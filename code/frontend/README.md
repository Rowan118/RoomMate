# How to run
For the time being, host the server locally using
`python3 -m http.server 8000` 
For Windows, use python instead of python3.
Then open your web browser to
`http://localhost:8000`
You can also use `http://127.0.0.1:8000`. Keep using the same hostname when
logging in and navigating the site: browsers keep cookies for `localhost` and
`127.0.0.1` separately, so switching between them requires logging in again.
Make sure the backend is also running.
See also: the backend/README.md
